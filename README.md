# Credit Wise Loan System

Built an end-to-end supervised Machine Learning pipeline to predict loan approval status using classification algorithms such as K-Nearest Neighbors (KNN), Logistic Regression, and Naive Bayes.

## Project Overview
The project focuses on analyzing applicant data and predicting whether a loan should be approved or rejected based on various financial and demographic features.

## Key Features
- Performed Exploratory Data Analysis (EDA) to identify patterns and insights from the dataset
- Implemented data preprocessing and feature engineering techniques
- Built and compared multiple supervised Machine Learning models:
  - K-Nearest Neighbors (KNN)
  - Logistic Regression
  - Naive Bayes
- Developed a binary classification pipeline for loan approval prediction
- Evaluated model performance using:
  - Precision
  - Recall
  - F1-Score
  - Accuracy

## Outcome
Successfully developed a predictive loan approval system capable of classifying loan applications with effective performance metrics and comparative model analysis.
